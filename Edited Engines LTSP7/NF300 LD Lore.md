# NF300 LD

Three cylinders of a **Honda Supra Fit**, engine code **NF100 LD** — which is
where the name comes from. NF100 LD, times three cylinders, is NF300 LD.

## The donor

BlueAutumnX5's own Supra Fit. Factory figures:

| | |
|---|---|
| Bore × stroke | 50.0 × 49.5 mm |
| Displacement | 97.1 cc |
| Compression | 8.8:1 |
| Valvetrain | 2 valves, SOHC, air-cooled single |
| Gearbox | 4-speed rotary, teeth 12-34 / 17-29 / 21-26 / 24-23 |
| Primary reduction | 4.058 |
| Final drive | 34/16 = 2.125 |
| Tyres | 2.50-17 |
| Wheelbase | 1222 mm |
| Kerb weight | 93 kg |

## What was built from it

Three of those cylinders on a single shared crankpin, banks at 45/0/−45
degrees — the arrangement a Harley V-twin uses, with a third cylinder added.
291.3 cc on paper; the simulator reads 292.

It keeps the donor's bore and stroke exactly, and sits at 9.0:1 against the
factory 8.8:1. It drives the Supra Fit's own drivetrain: the same four-speed
rotary box, the same 4.058 primary and 34/16 final drive, on the same 2.50-17
tyres. Vehicle mass is carried at 120 kg rather than the bike's 93 — a 292 cc
triple is a good deal heavier than the 97 cc single it replaces, and that 30 kg
is an estimate rather than a figure from any spec sheet.

Redline is 8000 rpm and **there is no rev limiter at all** — nothing cuts the
ignition, so it will run clean past the redline to around 12,800 if you hold it
there, the way an old bike does. Idle is about 1000 rpm.

The flywheel is deliberately larger than the Archangel template calls for
(180 mm rather than 124 mm). The template's own sizing left this engine with
about as much rotating inertia as a single 97 cc cylinder carries, and it
snapped back to idle far faster than any cub does.
